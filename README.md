# The Jamna Cafe and Restaurant Website

An attractive, responsive website for The Jamna Cafe and Restaurant featuring a modern design with smooth animations and intuitive navigation.

## Features

✨ **Modern Design**
- Beautiful gradient backgrounds and color scheme
- Responsive layout that works on all devices
- Smooth animations and hover effects

📱 **Responsive Layout**
- Mobile-first approach
- Works seamlessly on smartphones, tablets, and desktops
- Hamburger menu for mobile devices

🍽️ **Menu Section**
- Showcase of food and beverage offerings
- Menu cards with images and pricing
- Beautiful hover animations

📅 **Online Reservations**
- Easy-to-use reservation form
- Date and time selection
- Guest count selection
- Form validation

📍 **Contact Information**
- Location, phone, email, and hours
- Social media links
- Easy accessibility

✨ **Additional Features**
- Smooth scrolling navigation
- Sticky navigation bar
- Scroll animations for menu items
- Active nav link highlighting
- Fully functional contact form

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Customize the content, contact information, and images as needed

## Customization

### Update Business Information
Edit the following sections in `index.html`:
- Phone numbers
- Email addresses
- Location
- Hours of operation
- Menu items and prices

### Change Colors
Modify the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #8B4513;
    --secondary-color: #D2B48C;
    --accent-color: #FF6B35;
    --dark-color: #2C1810;
    --light-color: #FFF8F0;
}
```

### Replace Images
Update image URLs in the `<img>` tags to use your own photos
